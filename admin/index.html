Backup dos dados

Os dados ficam só neste navegador. Baixe um backup toda semana e guarde em local seguro (pen drive, nuvem). O arquivo contém dados de clientes e os hashes das senhas: não compartilhe.

Segurança

  • Sessão expira após 30 min sem uso (aviso 2 min antes)
  • Senhas com hash PBKDF2 (120.000 iterações)
  • Bloqueio de 5, 15 e 60 min após 5 senhas erradas
  • Auditoria encadeada por hash (detecta adulteração)
